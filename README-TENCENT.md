# 健身档案 - 腾讯云 EdgeOne Pages 部署版

这是从原 OpenAI Sites / Cloudflare 构建配置转换出的标准 Next.js 静态导出版本。

## EdgeOne Pages 推荐设置

- Framework preset / 框架预设：Next.js（如可选）
- Install command / 安装命令：`npm install`
- Build command / 构建命令：`npm run build`
- Output directory / 输出目录：`out`
- Node.js：20 或更高

## 本地运行

```bash
npm install
npm run dev
```

## 构建

```bash
npm run build
```

构建成功后静态文件位于 `out/`，可直接由静态托管平台发布。
